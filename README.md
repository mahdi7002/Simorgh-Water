# 🌊 Simorgh Water Cycle — سیمرغ چرخه آب

**سیستم جامع مدیریت چرخه کامل آب**  
از آسمان تا زمین، از طبیعت تا انسان، از بدن تا روح

> نسخه حرفه‌ای و قابل‌اجرا — الهام‌گرفته از بهترین پروژه‌های جهانی آب (۲۰۲۵–۲۰۲۶)

---

## الهام‌گرفته از چه پروژه‌هایی؟

| پلتفرم / پروژه | چه چیزی از آن گرفته شد |
|----------------|------------------------|
| **Xylem Vue (GoAigua)** | نمای یکپارچه چرخه آب + کاهش ۳۰٪ NRW در والنسیا |
| **Bentley OpenFlows WaterSight** | Digital Twin شبکه و شبیه‌سازی سناریو |
| **Siemens SIWA** | نشت‌یابی هوشمند و بهینه‌سازی پمپاژ |
| **Schneider EcoStruxure Water Advisor** | داشبورد تصمیم‌یار برای مدیران |
| **TaKaDu** | تشخیص زودهنگام رویدادها در شبکه |
| **South Bend (Xylem)** | کاهش ۸۰٪ سرریز فاضلاب ترکیبی |
| **Singapore PUB** | نگاه کل‌نگر به امنیت آب |
| **قنات و فرهنگ یزد** | لایه آگاهی و حکمت (منحصربه‌فرد این پروژه) |

---

## پنج لایه سیستم

1. **چرخه طبیعی** — باران، خاک، رودخانه، سد، خشکسالی  
2. **زیرساخت شهری** — شبکه توزیع، نشت (NRW)، فشار، تصفیه  
3. **ساختمان** — جریان لحظه‌ای خانه، تشخیص نوع مصرف، پیشنهاد بهبود  
4. **انسان** — آبرسانی بدن، نیاز روزانه، یادآور  
5. **آگاهی (روح)** — سطح آگاهی، حکمت روزانه، برنامه عمل

## نصب و اجرا (سریع)

```bash
# کلون (یا کپی فایل‌ها)
cd Simorgh-Water

# نصب وابستگی‌ها
pip install -r requirements.txt

# اجرای داشبورد
python -m uvicorn api.main:app --host 0.0.0.0 --port 8080 --reload
```

سپس مرورگر را باز کنید:

```
http://localhost:8080
```

### APIها

| مسیر | توضیح |
|------|--------|
| `GET /` | داشبورد کامل |
| `GET /api/health` | سلامت سیستم |
| `GET /api/natural` | وضعیت لایه طبیعت |
| `GET /api/city` | وضعیت زیرساخت شهری |
| `GET /api/holistic` | نمای جامع + داستان + گلوگاه‌ها |
| `GET /api/story` | داستان اتصال لایه‌ها |
